# MiniPS — 网页版图像编辑器

纯前端实现的迷你 Photoshop：零依赖、无需构建、无需服务器。
**双击 `index.html` 即可使用**（或任意静态服务器托管）。

## 功能

- **文件**
  - 打开图像（替换文档）、导入为图层、拖拽图片进画布直接导入
  - 导出 PNG / JPEG
  - 保存 / 打开工程文件 `.psx`（完整保留图层、不透明度、混合模式）
- **图层**
  - 新建 / 复制 / 删除 / 重命名（双击名字）/ 上下移动
  - 显示隐藏、不透明度、16 种混合模式（正片叠底、滤色、叠加、柔光……）
  - 向下合并、合并可见图层、拼合图像
- **选区**（Shift 加选 / Alt 减选）
  - 矩形选框、套索、多边形套索（双击/回车闭合）、魔棒（容差、连续）
  - 全选 / 取消选择 / 反选，蚂蚁线动态显示
  - 复制 / 剪切 / 粘贴为新图层 / 删除；移动工具可直接搬移选区内容
  - 画笔、橡皮擦、油漆桶自动被选区裁剪
- **绘制工具**：画笔（大小/硬度/流量）、橡皮擦、油漆桶（容差）、吸管、
  文字（字号/字体）、形状（矩形/椭圆、空心）、裁剪、抓手、缩放
- **图像**：图像大小、画布大小（九宫定位）、旋转 90°/180°、翻转
- **调整**：亮度/对比度、色相/饱和度、高斯模糊（实时预览）、反相、去色
- **其他**：撤销/重做（20 步）、Ctrl+滚轮缩放、空格平移、暗色 UI

## 技术说明

- 每个图层是一张离屏 canvas，合成时按不透明度 + 混合模式依次绘制
- 选区存为蒙版 canvas，轮廓用 Moore 邻域跟踪描出（蚂蚁线与裁剪共用同一路径）
- 泛洪（魔棒/油漆桶）为扫描线 BFS + 通道差容差
- 调整滤镜基于 Canvas2D `ctx.filter`，实时预览、可选区裁剪
- 撤销采用快照栈（toDataURL 序列化，上限 20 步）
